# 受入基準（システム共通基盤）

| 項目 | 内容 |
|------|------|
| 作成日 | 2026年5月28日 |
| バージョン | 1.0 |
| 対象 | Webシステム共通基盤（sys） |

---

## 1. 認証・セッション管理

### AC-SYS-001: ログイン機能（FR-SYS-001, UC-SYS-001）

| 項目 | 合否条件 |
|------|----------|
| **正常系** | 正しいユーザー名・パスワードでログインできる |
| **異常系** | 間違ったパスワードではログインできない |
| **異常系** | 存在しないユーザー名ではログインできない |
| **JWT発行** | ログイン成功後、httpOnly CookieにJWTが設定される |
| **セッション保存** | ログイン成功後、セッション情報がJSONファイルに保存される |
| **リダイレクト** | ログイン成功後、ダッシュボード画面に遷移する |

### AC-SYS-002: ログアウト機能（FR-SYS-002, UC-SYS-002）

| 項目 | 合否条件 |
|------|----------|
| **正常系** | ログアウトボタンをクリックすると、JWT Cookieが削除される |
| **セッション削除** | ログアウト後、サーバーのセッション情報が削除される |
| **リダイレクト** | ログアウト後、ログイン画面に遷移する |
| **再アクセス** | ログアウト後、認証が必要なページにアクセスすると、ログイン画面にリダイレクトされる |

### AC-SYS-003: JWT検証（FR-SYS-003, FR-SYS-005, NFR-SYS-001）

| 項目 | 合否条件 |
|------|----------|
| **httpOnly** | JWTがhttpOnly Cookieに設定され、JavaScriptからアクセスできない |
| **有効期限** | JWTの有効期限が切れた場合、401 Unauthorizedが返される |
| **改ざん検証** | JWTが改ざんされた場合、401 Unauthorizedが返される |
| **セキュリティ** | XSS攻撃でJWTが窃取されないことを確認する |

### AC-SYS-004: セッション管理（FR-SYS-004）

| 項目 | 合否条件 |
|------|----------|
| **保存** | セッション情報が `backend/data/sessions/` に保存される |
| **DAL経由** | セッション情報の読み書きがDAL経由で行われる |
| **有効期限** | セッションの有効期限が管理される |

## 2. ユーザー管理

### AC-SYS-010: ユーザー登録（FR-SYS-010, UC-SYS-006）

| 項目 | 合否条件 |
|------|----------|
| **正常系** | 管理者が新しいユーザーを登録できる |
| **異常系** | 既存のユーザー名では登録できない |
| **パスワードハッシュ化** | パスワードがハッシュ化されて保存される（平文で保存されない） |
| **権限設定** | ユーザーに管理者権限または一般ユーザー権限を設定できる |
| **保存** | ユーザー情報が `backend/data/users.json` に保存される |

### AC-SYS-011: ユーザー編集（FR-SYS-011, UC-SYS-007）

| 項目 | 合否条件 |
|------|----------|
| **正常系** | 管理者がユーザー情報を編集できる |
| **権限変更** | ユーザーの権限を変更できる |
| **更新** | 変更内容が `backend/data/users.json` に反映される |

### AC-SYS-012: ユーザー削除（FR-SYS-012）

| 項目 | 合否条件 |
|------|----------|
| **正常系** | 管理者がユーザーを削除できる |
| **削除** | 削除されたユーザーが `backend/data/users.json` から削除される |
| **ログイン不可** | 削除されたユーザーでログインできない |

### AC-SYS-013: パスワード変更（FR-SYS-014, UC-SYS-008）

| 項目 | 合否条件 |
|------|----------|
| **正常系** | ユーザーが自分のパスワードを変更できる |
| **現在のパスワード検証** | 現在のパスワードが正しくない場合、変更できない |
| **確認入力** | 新しいパスワード（確認）が一致しない場合、変更できない |
| **ハッシュ化** | 新しいパスワードがハッシュ化されて保存される |

## 3. アプリプラグイン機構

### AC-SYS-020: マニフェスト読み込み（FR-SYS-020, FR-SYS-021, UC-SYS-003）

| 項目 | 合否条件 |
|------|----------|
| **自動認識** | `apps/` ディレクトリに配置されたアプリが自動的に認識される |
| **manifest.json読み込み** | システム起動時に `apps/*/manifest.json` が読み込まれる |
| **メタ情報表示** | アプリ名・バージョン・エントリーポイントが正しく表示される |
| **エラーハンドリング** | manifest.json が不正な場合、エラー状態として表示される |

### AC-SYS-021: アプリ有効化・無効化（FR-SYS-022, FR-SYS-027, UC-SYS-004, UC-SYS-005, UC-SYS-011）

| 項目 | 合否条件 |
|------|----------|
| **有効化** | 管理者がアプリを有効化できる |
| **無効化** | 管理者がアプリを無効化できる |
| **メニュー表示** | 有効化されたアプリのみがナビゲーションメニューに表示される |
| **URL直接アクセス時のリダイレクト** | 無効化されたアプリのURLに直接アクセスした場合、ポータルページ（`/portal`）にリダイレクトされる |
| **通知メッセージ** | ポータルページに遷移後、「このアプリは現在利用できません」と通知が表示される |
| **APIアクセス拒否** | 無効化されたアプリのAPIエンドポイントを呼び出した場合、403エラーが返される |
| **保存** | 有効化状態が `backend/data/apps.json` に保存される |

### AC-SYS-022: アプリ独立データ領域（FR-SYS-025, FR-SYS-026）

| 項目 | 合否条件 |
|------|----------|
| **独立性** | 各アプリのデータが `apps/<app-name>/backend/data/` に保存される |
| **直接参照禁止** | アプリが他のアプリのデータに直接アクセスできない |
| **API経由** | アプリ間データ共有が必要な場合、共通APIを経由する |

### AC-SYS-028: システムポータルページ（FR-SYS-028, UC-SYS-016）

| 項目 | 合否条件 |
|------|----------|
| **ログイン後表示** | ログイン後、ポータルページ（`/` または `/portal`）が表示される |
| **アプリカード表示** | 有効化されたアプリのみがカード形式で表示される |
| **無効化アプリ非表示** | 無効化されたアプリは表示されない |
| **カード内容** | 各アプリカードにアイコン・名前・説明・起動ボタンが含まれる |
| **システム情報表示** | ユーザー名・権限・ログイン時刻が表示される |
| **ホームボタン** | ヘッダーにホームボタンが表示される |
| **ホームボタン機能** | ホームボタンクリックでポータルページに遷移する |

## 4. 共通API提供
